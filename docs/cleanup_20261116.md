## 后续可以进一步决定的范围

1. 旧训练的 epoch 快照是否只留最终模型；删除后仍可读已有指标，但不能直接重新评估或从该中间 epoch 恢复。
2. A/M、Stage 4、weather round 等历史实验各保留哪些模型和逐 query 结果；它们仍有研究价值，不能按“旧”直接判断无用。
3. 87 对图的历次生成、screening 和 Prompt pilot 是否只保留汇总报告；当前审核校准和活跃修复引用的文件必须保留。
4. SD、IC-Light、跟踪等非当前主线组件是否彻底退役；要同时核对代码引用、硬链接和其他项目使用情况。
5. Git 中的历史大文件是否需要专门整理；这属于历史维护，不在本轮轻量清理中执行。
