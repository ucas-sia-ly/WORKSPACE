# 2026-11-13 夜间数据汇总与清理

根据用户要求，仅保留当前约六万张夜间图相关的生成内容，并清理可删除的旧输出。

## 汇总结果

- 61,984 个唯一地点 / 唯一生成 ID / 精确真实源图，23 个城市，29 类非汞灯风格。
- 46,712 张历史保留图 + 13,206 张原 Prompt 续生成图 + 2,066 张汞灯替代图。
- 原图、训练尺寸生成图、高清生成图、原始 sidecar 逐文件 SHA256 核验。
- 统一目录 `outputs/night_dataset_v1/pairs/<city>/<place_id>`，提供 JSONL、TSV、SQLite 索引。
- 图像使用硬链接，原图使用符号链接，没有额外复制整批图，没有重编码或重生成。

## 第一轮实际删除

- **252,234 个文件，实际释放 103.76 GiB**。
- 旧 weather_v3/weather_v4、早期 pilot、诊断与 Prompt 风格试验图库。
- 已校验回传的 staging/incoming 缓存与完成任务的服务临时输出。
- 非当前主线的 V4/V5 生图、旧微调、Prompt 试验和性能探针入口及其专属测试、文档。
- 多余 epoch checkpoint、大型逐图曝光轨迹和可重建 smoke/probe tensor。

逻辑删除大小约 162.49 GiB，其中一部分本来就是硬链接，因此不等于实际释放空间。实际释放量按清理前后文件系统空闲字节计算。

## 保留内容

- 真实数据集、下载模型、本批全部图像和精确源图映射。
- 当前冻结依赖、Prompt、原始运行来源、生成账本和必要数据划分。
- 正式训练报告、指标、最终 checkpoint 及仍被引用的输入 checkpoint。
- 仍被引用的 `outputs/coverage_run/checkpoint_epoch_050.pt`。
- 根据之前的明确要求，Reliability V2 checkpoint 和实验记录继续保留。

本批冻结代码可能仍导入名称带旧版本号的模块，不以文件名判断是否可以删除。保留了后续质量检查和训练预检查需要的内容审核实现。

旧实验中引用已删除图库或中间 checkpoint 的路径不会再用于恢复；历史报告保留其原始文字。本次不修改模型参数，不启动任何训练或重新生成。

## 审计与验收

`outputs/maintenance/night_cleanup_20261113/` 保存：

- `plan.json`：逐文件清单、保留路径、源代码依赖、文件身份与修改时间。
- `deleted.jsonl`：实际删除记录。
- `result.json`：实际释放空间、数据集数量及计划哈希。
- `extra_deleted.jsonl`：旧展示附件、Python 缓存等补充清理记录（若存在）。

删除前先校验完整数据集索引，再检查所有候选文件的 inode、大小、mtime 和小文本哈希；拒绝数据/模型目录及符号链接穿透。

清理后，保留的生成与恢复 CPU 测试 **471 项通过**，包含新增精确配对、汇总恢复及删除保护测试。训练/生成 GPU 均未启动。清理后再次对全部 61,984 对执行完整文件哈希复核，均一致；1,046 项冻结代码/记录依赖检查通过。

补充清理删除 44 个旧展示附件、Python/服务缓存文件，另释放约 4.3 MiB；总删除 252,278 个文件。汇总结果见同目录 `summary.json`。
